# Desafio 50+ - Pilates e Saúde

Funil interativo de Pilates para o público 50+ com quiz personalizado, carregamento otimizado de imagens e Meta Pixel integrado.

## 🚀 Funcionalidades

- **Quiz Interativo**: Fluxo de perguntas para personalização de treino de Pilates.
- **Assets Locais**: Imagens, fontes e estilos servidos localmente com performance máxima.
- **Meta Pixel**: Rastreamento oficial integrado com ID `2126723871304047` (`PageView`).
- **Design Responsivo**: Adaptado para dispositivos móveis e desktop.

## 📁 Estrutura de Arquivos

- `index.html`: Página principal com todo o quiz e inicialização do funil.
- `css/`: Estilos CSS compilados.
- `fonts/`: Fontes do projeto (Inter, Montserrat).
- `images/`: Imagens do quiz e produtos.
- `js/`: Scripts JavaScript do Next.js e dados do funil (`funnel_data.js`).
- `_next/`: Módulos estáticos de fallback do Next.js.
